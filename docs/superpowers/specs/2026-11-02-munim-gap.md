# What Munim has that Munshi lacks (2 Nov)

Sources: Munim's own docs (foodops-os `docs/plan/*`, foodops-intel README, munim-paytm export docs), and Munshi's code on
`ui/refresh` @ baffac4. Read for design only: nothing is copied (fresh-code rule).

## Built in Munshi but not wired (cheapest wins)

| Piece | What it would do | Where it stops today |
|---|---|---|
| `explainFinding` | "Why?" on a finding: the agent explains it from its rows | agent tests only, no UI |
| `draftFix` + recipes | "Draft the fix" on a finding, into the tray | agent tests only; three recipes exist |
| `narrateBrief` | the morning brief in Munshi's words, every figure a cell | the tick runs with no narrator: template lines |
| `draftReply`, `draftOrder`, `transcribe` | inbox: a voice note heard, a reply or an order drafted | inbox can only mark handled/ignored |
| `writeCampaignCopy` | AI copy for a campaign | owner types the copy |
| snooze / dismiss a finding | the owner quiets a finding | core only |
| item / price forms, stock grid apply | catalogue edits through drafts | grid "Send for approval" only previews |
| roster, holidays, order cancel/reschedule | staff and order follow-ups | core only |
| `counter`, `settlements` agents | listed in AI staff, no code | missing |

## In Munim, missing in Munshi

| Area | Munim | Munshi today |
|---|---|---|
| Agents as a team | a manager that routes and takes @Name, specialist desks with track records (proposed / approved / rejected / stale / abstained), run log and replay | one Ask loop; office shows the brief and the scene |
| Negotiation | the same request to three simulated suppliers; a deal review that refuses a hidden minimum-order clause; ends in a purchase draft | none |
| Investigations | step / plan / auto modes; a margin bridge that balances | none |
| Memory | episodic, semantic (wiki, claims, embeddings), procedural | none |
| Graph | supplier → item → shop edges; "what does a price rise touch" | none |
| Threads | ask threads with a rolling summary | single questions |
| Always-on | a 15-minute sweep, up to ten narrated findings a day, a narrated brief | hourly SQL watchers, template brief |
| Cost | priced spend rows, a monthly money cap (soft cap → cheaper model → template; hard cap → rules only) | daily call caps; tokens discarded |
| Evals | headline numbers from seeded answer keys (planted leaks), each gate red-proved | per-feature gates; no headline numbers |
| Voice out | answers and the brief read aloud from cited cells (Hindi and English) | voice in only |
| Impact | Munim Cares: surplus near expiry offered to recipients (simulated) | expiry watcher only |
| Forecast | seasonal model with a backtest that must beat naive | none |
| Onboarding | one-click shop, checklist, narrated tour | demo picker, sandbox |
| Import | menu photo, POS / payout / bank files mapped from headers | settlement CSV only |
| Restaurant | KDS, storefront ordering, dish margins | not in scope (shop sites instead) |
